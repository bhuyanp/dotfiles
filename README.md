
# Dotfiles

Usage
-----

Install (clone to /tmp and run installer):

```bash
rm -rf /tmp/dotfiles && git clone --depth=1 https://github.com/bhuyanp/dotfiles.git /tmp/dotfiles && bash /tmp/dotfiles/install.sh
```

This will clone the repository into `/tmp/dotfiles` and execute the `install.sh` script from that clone.
